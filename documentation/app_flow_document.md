# SailIQ App Flow Document

## Onboarding and Sign-In/Sign-Up
A new user typically arrives at the SailIQ landing page, where they can see a brief introduction about sailing video analysis, coaching features, and subscription plans. From this page, they click the "Get Started" or "Sign Up" button, which opens Clerk’s secure sign-up modal. Within this modal, they can choose to register via email and password or use a social login provider, such as Google, if enabled. When registering with email, they enter their name, email address, and a password and then click "Create Account." Clerk sends a verification email. The user opens their inbox, clicks the verification link, and is then redirected back to the app to complete their profile.

If a user already has an account, they click "Sign In" on the landing page or the header, which presents Clerk’s sign-in modal. They supply their email and password or social provider credentials and click "Sign In." Clerk manages the session and, on success, redirects the user to the main dashboard. If a user forgets their password, they click "Forgot password" in the sign-in modal, enter their email, and receive a password reset link. Clicking that link leads them to a secure page to set a new password. Once reset, they return to the sign-in view and enter their new credentials to access SailIQ.

Signing out is handled via a "Sign Out" button in the user menu on the dashboard header. When clicked, the session ends and the user is returned to the landing page. Throughout this flow, Clerk handles all authentication, session cookies, and password management securely on the server.

## Main Dashboard or Home Page
Once signed in, a Sailor, Coach, or Club Admin lands on the SailIQ Dashboard. The page displays a top navigation bar showing the SailIQ logo on the left, a search field in the center for quick session lookup, and a user avatar on the right that opens the account menu. On the left side of the screen, a vertical navigation menu lists Dashboard, Upload Session, My Sessions, Chat Coach, and Settings. The main content area shows a welcome message with the user’s name and a high-level overview of recent sessions. Sailors see their latest video session thumbnails with quick links to view details, while Coaches and Club Admins see a combined feed of sessions from their team or club members. A charts widget at the top presents summary metrics such as average boat speed, number of sessions this month, and upcoming subscription renewal date. Every element on this page is clickable, guiding the user to detailed views or actions.

Clicking "Upload Session" in the navigation moves the user to a page where they can start a new analysis. Selecting "My Sessions" reveals a paginated list of past uploads. Coaches and Admins see an additional filter bar above the session table that lets them choose sailors, date ranges, or boat classes. Clicking a session title transports the user to the session details page.

## Detailed Feature Flows and Page Transitions
When a Sailor or Coach clicks "Upload Session," they land on the Upload page. Here, they fill out a form with session metadata such as boat class, location, wind conditions, and date. Below the form, they choose a video file from their device. Clicking "Start Upload" calls a Next.js API endpoint that generates a secure Supabase Storage URL. The file is then uploaded directly from the browser to Supabase. A progress bar shows upload status. When complete, the app automatically calls another API route to enqueue the video analysis job in the background service. The user sees a confirmation message and is given a link to the new session details page.

On the session details page, the top section displays the uploaded video thumbnail, session metadata, and analysis status indicator. If the analysis is still running, the page polls the backend via React Query every few seconds. Once the analysis concludes, performance metrics appear in a grid of charts powered by Recharts. Each chart has a tooltip and a filter dropdown to toggle between boat speed, heel angle, and manoeuvre count. Below the charts, a table lists individual manoeuvres with timestamps. Clicking a row in this table loads a video clip of that specific manoeuvre in an inline video player.

The Chat Coach feature is accessible via its own menu item. Clicking it opens a chat interface on the right side of the screen where the user types questions about their performance. When they send a question, the app calls the RAG API route, which queries Supabase Vector using LangChain and returns contextual tips. The response displays as chat bubbles, and each tip links back to relevant session timestamps.

Club Admins have an extra navigation item called "Club Management." Clicking that opens a page where they can invite sailors or coaches via email. When they send an invite, Clerk emails a registration link preconfigured with the user’s role. Admins can also view a list of pending invites and revoke or resend them.

## Settings and Account Management
The Settings page is reachable from the sidebar or the user avatar menu. The first tab is "Profile," where users can update their name, contact email, and default boat class. They click "Save" to apply changes. The second tab is "Preferences," where they toggle notification settings such as email alerts for completed analyses or subscription reminders. The third tab is "Billing." Here, users see their current subscription plan, next billing date, and payment method. They click "Manage Subscription" to open the Stripe-hosted customer portal in a new tab. In that portal, they can upgrade or downgrade their plan, update their credit card, and view past invoices. Closing the portal returns them to the Settings page.

From any subpage in Settings, a breadcrumb at the top allows users to navigate back to the Dashboard or any other main section. All changes in Settings prompt a confirmation toast message on success.

## Error States and Alternate Paths
If a user attempts to upload an unsupported file type or a file larger than the allowed limit, the upload form displays a red error message beneath the file input field explaining the limit and accepted formats. If the network connection drops during upload, the progress bar turns red and a modal appears with a "Retry Upload" button. Clicking retry reinitiates the upload process from the beginning.

When API requests fail due to server errors or timeouts, a dismissible banner appears at the top of the current page, stating "Something went wrong. Please try again later." In critical flows, such as payment or signup, the app automatically retries once before showing the error message. Unauthorized requests, such as a Sailor trying to access the Club Management page, result in a redirect back to the Dashboard with an alert stating "You do not have permission to view that page."

In the Chat Coach interface, if the vector database is unavailable, the chat input is disabled and a message reads "Chat service is temporarily unavailable." Once connectivity is restored, the input is re-enabled without losing the user’s draft question.

## Conclusion and Overall App Journey
A typical user journey begins with a Sailor signing up, verifying their email, and completing their profile. They log in, upload their first sailing video, and watch the progress bar as their session is sent to Supabase Storage and then analyzed by the external service. After a short wait, they see detailed performance charts on their session details page. Curious about improving their tacks, they switch to Chat Coach and receive AI-powered advice drawn from sailing manuals. Over time, they explore their past sessions through the My Sessions list and monitor their metrics trends on the Dashboard. If they ever need to update billing details or manage notifications, they head to Settings. Coaches and Club Admins follow a similar path but gain additional controls, such as inviting team members and viewing multiple sailors’ sessions. Throughout this flow, Clerk ensures secure authentication, Supabase manages storage and database operations, Stripe handles payments, and Next.js glues every part together seamlessly, creating a cohesive experience from sign-up to expert sailing insights.
